## PYTHON AUTOMATION SCRIPT
## Overview
This project is a menu-driven python automation tool that performs basic file and directory operations. It demonstrates the use of :
-os module for system operations 
-Logging module for tracking activites
-Exception handling for robustness 
-user input for dynamic execution
## Objectives
-Automate basic file management task 
-implement clean and modular python code
## Features
-Create dictionaries 
-list files in a dictionary
-create and write to files
## Tech Stack
-Language: Python
-Modules used : os logging
## How to run the program
--Automation menu 
-1. Create dictionary
2.Liast files
3.Write to files
4.Read file
5.Exit
